# Curated reference sources

These are real, independent, unmodified reference fonts, **not Mashi community submissions or Mashi editor exports**. The font names, embedded metadata, copyright, and full upstream SIL Open Font License 1.1 files are unchanged. There is no claim of endorsement by the designer, SMC, or Google.

Both binaries and licence files are pinned to the official [google/fonts repository, revision 6c1dbe27dcf7d817d4b62cec033ba77fa8e2a5ec](https://github.com/google/fonts/tree/6c1dbe27dcf7d817d4b62cec033ba77fa8e2a5ec). The source URLs and SHA-256 font hashes appear in each `metadata.json` and `NOTICE.txt`. Original upstream licence files are stored beside the fonts and included verbatim in downloads.
