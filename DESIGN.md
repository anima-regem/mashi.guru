# Design decisions

Reading this as: a minimal Malayalam font directory for readers and font makers, with an editorial specimen language and native CSS.

Design variance 5, motion 2, visual density 3. Cool off-white background, black text, one muted green accent. Native system UI typography keeps navigation quick; the actual licensed Malayalam fonts are the visual material. No decorative graphics, image dependencies, generic marketing claims, slogans, version labels, or ornamental status badges. Six-pixel corners for controls; font rows are separated by a rule rather than elevated cards.

The page starts directly with the font collection and live preview controls. Repeated static specimens and contribution instructions are omitted; the publish action opens the full GitHub guide. Origin filters appear only when both community and reference fonts exist. Every element helps preview, find, attribute, download, or submit a font. Default system dark mode, reduced-motion support, visible focus, skip link, native details, labelled controls, and working no-JavaScript downloads are intentional.
